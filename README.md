### مخصص لطلبة: السنة الرابعة مهندس - هندسة كيميائية

---

## ⚡ الميزات:
1. **فحص سحابي مستمر 24/7 كل 5 دقائق:** يعمل في السحابة حتى وجهازك مغلق.
2. **صامت تماماً (Zero Spam):** لا يرسل أي إشعار إلا إذا وُجد إعلان جديد وحقيقي يخص دفعتك.
3. **تنزيل مباشر للجدول (PDF):** زر مباشر لتنزيل الملفات فوراً بهاتفك.
4. **رابط الإعلان المحدد:** ينقلك مباشرة إلى المنشور المعني.

## ☁️ خيارات التشغيل السحابي 24/7 كل 5 دقائق (مجاناً):

### الخيار 1: عبر GitHub Actions (الأسهل)
1. أنشئ مستودعاً في GitHub واجعله **عاماً (Public)**.
   > **ملاحظة هامة:** المستودعات العامة في GitHub توفر دقائق تشغيل **غير محدودة ومجانية 100% للأبد**، بينما المستودعات الخاصة تعطي 2000 دقيقة فقط شهرياً. لا تقلق، مفاتيحك وروابطك السرية تظل مخفية ومحمية في قسم **GitHub Secrets** ولا يمكن لأحد رؤيتها.
2. ارفع ملفات هذا المجلد إلى المستودع.
3. أضف المفاتيح السرية في **Settings** > **Secrets and variables** > **Actions**:
   - `GEMINI_API_KEY`: مفتاح Gemini الخاص بك.
   - `NTFY_TOPIC`: `gp_constantine_chem4_alert_2026`
4. سيبدأ السيرفر بالفحص السحابي تلقائياً **كل 5 دقائق طوال الـ 24 ساعة دون توقف**.

### الخيار 2: عبر منصة Render.com (Background Worker مجاني 24/7)
- تم تضمين ملف `Procfile` في المشروع.
- يمكنك ربط المستودع بمنصة **Render.com** واختيار إنشاء **Background Worker** لتشغيل `monitor.py` على مدار الساعة طوال الشهر دون انقطاع.
